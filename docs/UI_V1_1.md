# Sentinel v1.1 — Premium UI Refresh

This release is a visual refinement only. It keeps the existing FastAPI backend, SQLite persistence, detection engine, case workflow, API surface, and report formats intact.

## What changed

- Calmer navy background with restrained teal accents.
- Softer contrast and more generous whitespace for long analyst sessions.
- Refined sidebar, navigation states, buttons, controls, badges, and dialogs.
- Rounded cards and panels with subtle depth instead of heavy borders.
- Cleaner tables with lower visual noise and clearer hover states.
- Improved investigation workspace and sticky analyst panel on desktop.
- Updated chart palette to match the UI.
- Responsive tuning for laptops, tablets, and mobile layouts.

## What did not change

- Detection rules and thresholds.
- Event ingestion and validation.
- SQLite schema and persisted cases.
- Alert evidence and analyst journal behavior.
- API endpoints.
- Export formats.

The visual direction is intentionally product-like rather than portfolio-like: calm, precise, and suitable for a SOC workflow.
