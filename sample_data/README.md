# Synthetic scenario library

All 553 events are generated by `app/demo.py` with a fixed seed of 42. They contain no passwords, tokens, malware, or real operational records. All source addresses are documentation literals.

Both formats represent the same immutable event IDs; importing one after the other skips duplicates. Regenerate with `python -m app generate-samples`.

| Scenario | Evidence | What to inspect |
| --- | --- | --- |
| Business-hours baseline | 480 dispersed successes/failures | Normal volume and outcome ratios |
| Failed streak followed by success | `198.51.100.42` / `muhammed` / VPN | SOC-001 and critical SOC-002 |
| Failed-only streak | `198.51.100.88` / `svc_reports` | Stale credentials versus unexpected access attempts |
| Privileged successes | `admin`, `svc_backup`, `root` | Approved work windows and account ownership |
| Outside-hours successes | `selin` and `root` | Europe/Istanbul schedule and UTC conversion |
| Multiple accounts | `203.0.113.77` / `staff_01..12` | Distinct failed accounts, not attempt count |
| Fictional watchlist | `203.0.113.66` / `omar` | Contextual watchlist hit and success-after-failures |
| Authentication burst | `203.0.113.180` / `burst_1..6` | Volume, mixed outcomes, account diversity |

With default rules in a fresh database: **553 events, 18 alerts, 2 critical, 14 high, 2 medium, 94 failed logins, 459 successful logins, and 38 unique sources**.

Alert counts are intentionally not identical to scenario counts: one event can support multiple rules. SOC-007 can include nearby baseline events in its rolling window. Event time is October 1, 2026 UTC; after-midnight Istanbul local logins may occur on October 2.
